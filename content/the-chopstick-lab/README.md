# The Chopstick Lab content

Put project-specific source material for The Chopstick Lab here. This folder is
kept separate from `library/`, which contains reusable Godot tools and assets.

See [Projects made with tcl-studio](PUBLISHED_WORK.md) for the public channels
where work made with this library is shared.

- `images/` — logos, illustrations, thumbnails, and image references
- `qr-codes/` — QR-code images and the destination information used for them
- `demo-videos/` — video references, previews, and exported demonstrations
- `references/` — scripts, research notes, links, briefs, and other supporting
  material

Use descriptive file names, for example `2026-09-planet-orbits-reference.png`
or `youtube-channel-qr.png`.
